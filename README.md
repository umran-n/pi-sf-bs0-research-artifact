## Central observed result

> **Silence is not clearance.**

All seven canonical native DM-07 observations failed the same closed-world exclusion test. The relevant regulated-financial-institution evidence state remained **UNKNOWN**, requiring a **HOLD** screening disposition under the workflow's mandatory-clearance rule.

This is an observed 7/7 result on the canonical DM-07 case. It is **not** asserted as a universal failure probability for LLMs.

## Research boundary

This repository supports one workflow-specific study. It does **not** establish:

- global model superiority;
- production qualification of any candidate;
- PI-OS efficacy;
- calibrated Governance Burden weights;
- causal effects of parameter scale or hidden reasoning effort.

The next empirical layer is a paired governed evaluation under PI-OS controls measuring Governance Delta against the frozen native baseline.
